# Alcance del Proyecto – SIGA

## Incluye
- Gestión de usuarios y roles.
- Registros administrativos (CRUD).
- Reportes exportables.
- Autenticación segura (JWT + bcrypt).

## No incluye
- Integración con sistemas de nómina o facturación externos.
- Aplicación móvil nativa.
- Migración automática de datos históricos.
