# Investigación Tecnológica – SIGA

## Criterios de selección
La selección del stack se basó en escalabilidad, facilidad de mantenimiento, seguridad, compatibilidad y rapidez de desarrollo.

## Tecnologías evaluadas

| Capa | Tecnología | Justificación |
|---|---|---|
| Frontend | React + TypeScript | Interfaces dinámicas y tipado seguro para paneles, formularios y reportes. |
| Backend | Node.js (NestJS / Express) | Estructura flexible para servicios y reglas de negocio. |
| Base de datos | PostgreSQL | Estabilidad e integridad para registros administrativos y permisos. |
| ORM | Prisma / TypeORM | Reduce errores en el acceso a datos y facilita migraciones. |
| Autenticación | JWT + bcrypt | Control de acceso seguro basado en roles. |
| API | REST + Swagger | Comunicación documentada entre frontend y backend. |
| Pruebas | Jest + Postman | Validación de endpoints y reglas de negocio. |
| Despliegue | Docker | Empaquetado reproducible del sistema. |

## Conclusión
El stack elegido permite construir SIGA de forma modular, segura y mantenible, alineado con los procesos de ISO/IEC 29110.
