# Matriz de Riesgos – SIGA
## Criterios de evaluación
Cada riesgo se evalúa según su probabilidad (Alta/Media/Baja) e impacto (Alto/Medio/Bajo), definiendo una acción de mitigación responsable.
## Riesgos identificados
| ID | Riesgo | Probabilidad | Impacto | Mitigación |
|---|---|---|---|---|
| R-1 | Retraso en la entrega de módulos | Media | Alto | Seguimiento diario en tablero Kanban. |
| R-2 | Conflictos al integrar ramas en GitHub | Media | Medio | Revisión cruzada antes de cada merge. |
| R-3 | Fuga de credenciales o datos sensibles | Baja | Alto | Uso de variables de entorno y cifrado bcrypt. |
| R-4 | Requisitos mal entendidos | Media | Alto | Validación de criterios de aceptación con el equipo. |
| R-5 | Pérdida de trazabilidad documental | Baja | Medio | Documentación versionada en carpeta docs/. |
## Notas
Matriz alineada a la gestión de riesgos de la norma ISO/IEC 29110.
