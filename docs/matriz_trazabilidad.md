# Matriz de Trazabilidad – SIGA
## Objetivo
Relacionar cada requisito funcional con su módulo correspondiente y su caso de prueba, asegurando cobertura total y trazabilidad.
## Trazabilidad
| Requisito | Módulo | Caso de prueba | Estado |
|---|---|---|---|
| RF-1 Gestión de usuarios y roles | Módulo de autenticación | CP-01 | Pendiente |
| RF-2 Registros administrativos (CRUD) | Módulo administrativo | CP-02 | Pendiente |
| RF-3 Reportes exportables | Módulo de reportes | CP-03 | Pendiente |
| RF-4 Autenticación segura (JWT + bcrypt) | Módulo de autenticación | CP-04 | Pendiente |
## Notas
Trazabilidad construida a partir de los requisitos funcionales documentados (KIS-2) y alineada al aseguramiento de calidad de la norma ISO/IEC 29110.
