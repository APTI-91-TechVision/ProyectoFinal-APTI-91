# Políticas de Calidad de Código – SIGA
## Nomenclatura
- Variables y funciones en camelCase.
- Componentes en PascalCase.
- Nombres descriptivos, sin abreviaturas ambiguas.
## Documentación
- Comentarios JSDoc en funciones y módulos complejos.
- README actualizado por cada módulo entregado.
## Control de versiones
- Una rama por funcionalidad (feature/...).
- Commits descriptivos con prefijo (Add, Fix, Update, Refactor).
- Revisión cruzada (peer review) antes de integrar a main.
## Revisión
- No se integran cambios sin pruebas básicas.
- Sin credenciales visibles en el código.
## Notas
Políticas alineadas a la gestión de configuración y al marco ético IEEE/ACM.
