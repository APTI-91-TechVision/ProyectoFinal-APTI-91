## Descripción breve

SIGA es una plataforma de software propuesta por TechVision Solutions para optimizar, automatizar y centralizar procesos administrativos en organizaciones de mediano a gran tamaño. El proyecto busca mejorar la eficiencia operativa, reducir costos administrativos y ofrecer herramientas de análisis en tiempo real para apoyar la toma de decisiones, aplicando buenas prácticas de gestión de proyectos y calidad con base en ISO/IEC 29110.
